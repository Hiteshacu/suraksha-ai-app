# Suraksha AI — Android app downloads

This repository only hosts the installable APK of **Suraksha AI**, a women-safety app for Android.

**Download:** https://github.com/Hiteshacu/suraksha-ai-app/releases/latest/download/SURAKSHA-AI.apk

Website: https://suraksha-ai-it55.onrender.com

## Install
1. Download `SURAKSHA-AI.apk` on your Android phone (Android 8.0+, 64-bit).
2. Open it and allow installs from your browser when Android asks.
3. Sign in, add an emergency contact, and enrol your voice in the Voice tab.

Each release lists the file's SHA-256 checksum so you can verify the download.
